# SWYNEX Final Data Analytics Project

## About the Project

This is my final Data Analytics project completed during my internship at SWYNEX Technologies.

In this project, I worked on the Titanic dataset and performed data cleaning, exploratory data analysis, visualization and dashboard creation.

## Objective

The main objective of this project is to analyze the Titanic dataset and understand the factors related to passenger survival.

The analysis includes:

- Gender
- Age
- Passenger Class
- Fare
- Survival

## Dataset

The Titanic dataset contains information about passengers.

The main columns used in this project are:

- Passenger
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

## Data Cleaning

I checked the dataset for missing values and duplicate records.

The data was cleaned and prepared before performing the analysis.

## Exploratory Data Analysis

I performed EDA to understand the data and find useful patterns.

The analysis includes:

- Overall survival
- Survival by gender
- Survival by passenger class
- Age distribution
- Fare analysis
- Passenger distribution

## Dashboard

I created a Power BI dashboard to present the important findings from the analysis.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- GitHub

## Key Insights

The analysis helped identify different survival patterns based on gender, passenger class, age and other passenger information.

## Conclusion

This project helped me understand the complete Data Analytics process, from data cleaning and analysis to visualization, dashboard creation and finding useful insights.
